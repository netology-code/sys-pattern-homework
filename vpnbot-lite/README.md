# VPN Bot Lite

Лёгкая переработка [mercurykd/vpnbot](https://github.com/mercurykd/vpnbot): VPN-сервер, которым полностью управляют из Telegram-бота.

| | vpnbot (оригинал) | VPN Bot Lite |
|---|---|---|
| Контейнеры | 12+ (nginx, php, xray, wg, ocserv, adguard, …) | **1** |
| Код бота | ~10 000 строк PHP в одном файле | ~1 700 строк Python (aiogram 3) |
| Протоколы | много, часть уже блокируется | **VLESS Reality** и **VLESS XHTTP** (без SNI), **Hysteria2**, **AmneziaWG** (для роутеров), **MTProto-прокси** для Telegram |
| Домен / SSL | нужен для части функций | **не нужен** |
| Обновление Xray/Hysteria | вручную | **кнопкой в боте**, с проверкой и откатом |
| Обновление бота | вручную | **кнопкой в боте** |

## Возможности

- **Пользователи**: добавить (можно пачкой), включить/отключить, удалить, срок действия, лимит трафика, сброс трафика.
- **Автоотключение** по истечении срока или лимита — с уведомлением админу.
- **AmneziaWG для роутеров**: кнопка «📡 AmneziaWG» в карточке пользователя присылает готовый `.conf` и QR — импортируется в Keenetic, OpenWrt, AmneziaVPN. Отключение/удаление пользователя применяется без обрыва остальных.
- **Прокси для Telegram** (MTProto на [telemt](https://github.com/telemt/telemt), fake-TLS с эмуляцией ответа настоящего сайта): раздел «📨 Прокси Telegram» — ссылка `t.me/proxy`, QR, смена ссылки; telemt обновляется кнопкой, как Xray. Маскируется под собственный адрес сервера `IP.nip.io`, поэтому имя сайта совпадает с IP.
- **Подписки**: одна ссылка на пользователя для Hiddify, v2RayTun, Happ, v2rayN, Streisand — приложение само подтягивает ключи, трафик и дату окончания. QR-код в боте и веб-страница с инструкцией.
- **Статистика**: трафик каждого пользователя, CPU/RAM/диск/аптайм сервера, состояние ядер.
- **Обновления**: проверка новых версий Xray и Hysteria2 на GitHub, установка одной кнопкой, проверка конфига новой версией, откат на предыдущую.
- **Настройки из бота**: SNI для Reality и передавать ли его в ссылках, вкл/выкл XHTTP, смена ключей, вкл/выкл Hysteria2, обфускация Salamander, блокировка рекламы, адрес сервера.
- **Бэкап**: файл базы по кнопке «💾 Бэкап»; восстановление — просто отправить файл боту.
- **Надёжность**: если ядро упало — бот перезапускает его сам; Docker перезапускает бота; BBR и UDP-буферы настраиваются при установке.

## Установка

Нужен VPS с Ubuntu 22.04/24.04 или Debian 11/12 (x86_64 или arm64), root-доступ.

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. На сервере:

```bash
apt-get update && apt-get install -y git
git clone https://github.com/ProffeSOr24/solution-template.git /opt/vpnbot
cd /opt/vpnbot/vpnbot-lite
./vpn.sh install <ТОКЕН_БОТА> <ВАШ_TELEGRAM_ID>
```

Скрипт поставит Docker, настроит ядро и запустит бота. Через минуту бот пришлёт сообщение «запущен» — нажмите `/menu`.

> Если на сервере стоит старый vpnbot — сначала остановите его (`cd /root/vpnbot && docker compose down`), иначе порт 443 будет занят.

### Порты

| Порт | Что |
|---|---|
| 443/tcp | VLESS Reality |
| 8443/tcp | VLESS XHTTP (Reality) |
| 443/udp | Hysteria2 |
| 51820/udp | AmneziaWG |
| 8444/tcp | MTProto-прокси Telegram |
| 2096/tcp | ссылки-подписки |

Меняются в `.env` (`XRAY_PORT`, `XHTTP_PORT`, `HY2_PORT`, `AWG_PORT`, `MTPROTO_PORT`, `SUB_PORT`), затем `./vpn.sh restart`. Если у хостера есть свой фаервол — откройте эти порты там.

### Подписки по https (нужно для Happ на телефоне)

Happ и некоторые другие приложения не принимают подписку по `http://`. Домен покупать не нужно:

```bash
./vpn.sh https        # подписки на https://<IP-через-дефисы>.nip.io:2443
./vpn.sh https 443    # или на стандартном порту, если 443/tcp свободен

# если на сервере уже есть сертификат (например, у старого vpnbot) — без Caddy и порта 80:
./vpn.sh https-cert /root/vpnbot/certs/cert_public /root/vpnbot/certs/cert_private
```

Скрипт возьмёт бесплатное имя вида `77-67-89-191.nip.io` (оно всегда указывает на ваш IP) и запустит Caddy, который сам получает и продлевает сертификат Let's Encrypt. Для проверки Let's Encrypt нужен свободный порт **80**. После этого ссылки в боте станут `https://…`.

## Как пользоваться

`/menu` → **👥 Пользователи** → **➕ Добавить** → отправьте имя, например `ivan`, или `ivan 30 100` (30 дней, 100 ГБ). Можно несколько строк сразу.

В карточке пользователя → **🔗 Ключи и QR** — бот пришлёт QR-код и ссылку-подписку. Её нужно отправить человеку:

- **Android / iOS**: Hiddify, v2RayTun, Happ — «Добавить из буфера» или сканировать QR.
- **Windows**: Hiddify или v2rayN — «Добавить подписку».
- **macOS**: Hiddify, Streisand.

### AmneziaWG на роутер

Карточка пользователя → **📡 AmneziaWG (роутер)** — бот пришлёт файл `имя.conf` и QR-код. Лучше завести отдельного пользователя на каждый роутер.

- **Keenetic** (KeeneticOS 4.2+): «Интернет» → «Другие подключения» → «WireGuard» → «Загрузить из файла» → выбрать `.conf`. Затем включить подключение и в «Приоритетах подключений» назначить его нужным устройствам или сделать основным.
- **OpenWrt**: установите `kmod-amneziawg`, `amneziawg-tools`, `luci-proto-amneziawg` (пакеты из [amneziawg-openwrt](https://github.com/amnezia-vpn/amneziawg-openwrt/releases) под вашу версию), затем «Network → Interfaces → Add new interface → AmneziaWG» → «Load configuration» и вставьте содержимое `.conf`.
- **Телефон / ПК**: приложение AmneziaVPN или AmneziaWG → импорт файла или QR.

Используются параметры AmneziaWG 1.0 (Jc/Jmin/Jmax/S1/S2/H1–H4) — их понимают все прошивки и клиенты. MikroTik AmneziaWG не поддерживает.

Если открыть ссылку-подписку в браузере, будет страница со статусом, QR-кодом и кнопкой «Копировать».

### Переезд AmneziaWG со старого vpnbot

Роутеры и телефоны со старыми конфигами продолжат работать без изменений: переносятся ключ сервера, маскировка (включая S3/S4/I1), порт, подсеть и все клиенты.

```bash
./vpn.sh import-awg wg0            # проверка: что будет перенесено (wg0 — порт 51820, wg1 — 51821)
./vpn.sh import-awg wg0 --apply    # перенос (старый бот должен быть остановлен)
```

## Обновления

**⬆️ Обновления** в боте показывает текущие и последние версии:

- **Xray / Hysteria2** — кнопка «⬆️ …» скачивает релиз с GitHub, проверяет, что он запускается и принимает конфиг, и перезапускает ядро. Если что-то не так — «↩️ Откатить».
- **Бот** — кнопка «⬆️ Обновить бота»: сервер делает `git pull`, пересобирает контейнер и перезапускается; после этого бот напишет «Бот обновлён».

- **AmneziaWG** собирается из исходников при сборке образа, поэтому обновляется вместе с ботом.

То же вручную на сервере: `./vpn.sh update`.

Образ бота собирается на GitHub (`.github/workflows/vpnbot-lite-image.yml`) и скачивается готовым — обновление занимает около минуты. Если готового образа нет или он ещё собирается, сервер соберёт его сам.

## Если IP сервера заблокировали

**Сторож.** Раз в час бот проверяет через check-host.net, доступен ли сервер из российских сетей. Если доступ пропал у всех провайдеров или у части из них, бот пишет админу. Проверить вручную: **📊 Сервер → 📡 Доступность из РФ**.

**Свой адрес вместо IP (DuckDNS).** Устройства подключаются к имени `ИМЯ.duckdns.org`, а бот каждые 5 минут сообщает DuckDNS текущий IP сервера. Если хостер сменит IP, на устройствах ничего менять не нужно.
1. Войдите на [duckdns.org](https://www.duckdns.org) через Google или GitHub, придумайте имя и скопируйте **token**.
2. На сервере: `./vpn.sh ddns ИМЯ ТОКЕН`.
3. Один раз обновите устройства: подписку в Happ, адрес пира на роутере (`ИМЯ.duckdns.org:ПОРТ`), `.conf` AmneziaWG.

**Максимальная маскировка** (нужен DuckDNS): `./vpn.sh stealth`. VLESS переезжает на стандартные порты 443 (Reality) и 8443 (XHTTP), в SNI указывается свой домен, совпадающий с IP. Всем, кто не является клиентом (DPI-проверки, браузеры), сервер показывает обычный сайт «Заметки» с настоящим сертификатом. В Happ после этого нажмите 🔄 у подписки, роутер и AmneziaWG не меняются. Откатить: `./vpn.sh stealth off`.

**Прокси Telegram (MTProto)** по умолчанию выключен: такие прокси активно ищут, и они «подсвечивают» IP сервера.

## Команды на сервере

```bash
./vpn.sh status    # состояние
./vpn.sh logs      # логи бота
./vpn.sh restart   # перезапуск (перечитывает .env)
./vpn.sh ddns ИМЯ ТОКЕН  # адрес ИМЯ.duckdns.org вместо IP
./vpn.sh stealth   # маскировка под свой сайт на 443 (off — откатить)
./vpn.sh update    # обновить бота
./vpn.sh stop      # остановить
./vpn.sh doctor    # вся диагностика одним выводом (без секретов)
```

Все данные (база пользователей, ключи, сертификаты, обновлённые ядра) лежат в `data/`. Чтобы переехать на другой сервер — установите бота там и отправьте ему файл бэкапа.

## Если не работает

- **Бот молчит** — `./vpn.sh logs`: проверьте `BOT_TOKEN` и `ADMIN_IDS` в `.env`. Бот отвечает только админам из `ADMIN_IDS`.
- **Клиент не подключается по Reality** — российские провайдеры режут Reality, в котором указан чужой сайт (SNI `microsoft.com`, `yandex.ru` на IP хостера). Поэтому по умолчанию ссылки **без SNI** (**⚙️ Настройки → SNI в ссылках: нет**) — клиент не называет сайт вовсе. Если и так не работает — используйте **XHTTP** (трафик идёт короткими запросами и не попадает под «заморозку» длинных соединений) или попробуйте другой порт (`XRAY_PORT` в `.env`, например `43000`). Обновите подписку в приложении после любых изменений.
- **Hysteria2 медленная или не работает** — у некоторых провайдеров режется UDP/QUIC: включите **Обфускация** в настройках или пользуйтесь XHTTP или Reality.
- **AmneziaWG: рукопожатие есть, интернета нет** — проверьте `cat /proc/sys/net/ipv4/ip_forward` (должно быть `1`, `./vpn.sh update` выставит) и что у хостера открыт `51820/udp`.
- **AmneziaWG не подключается вообще** — после смены ключей (**🔑 Новые ключи AWG**) старые `.conf` недействительны, выдайте заново.
- **Ядро упало** — **📜 Логи** в боте покажут причину; **📊 Сервер → ♻️ Перезапуск ядер**.
- **В ключах неверный IP** — **⚙️ Настройки → 📍 Адрес сервера** (или `SERVER_HOST` в `.env`).

## Структура

```
vpnbot-lite/
├── app/
│   ├── main.py      запуск: бот, сервер подписок, фоновые задачи
│   ├── bot.py       меню и обработчики Telegram
│   ├── service.py   настройки, ссылки, применение конфигов, учёт трафика
│   ├── cores.py     Xray, Hysteria2, AmneziaWG: конфиги, процессы, обновления
│   ├── sub.py       HTTP-подписки
│   ├── db.py        SQLite
│   └── config.py    переменные окружения
├── Dockerfile
├── docker-compose.yml
├── vpn.sh           установка и обслуживание
└── .env.example
```
