# Домашнее задание к занятию «Уязвимости и атаки на информационные системы» - `Иванов Федор`

### Задание 1

Скачайте и установите виртуальную машину Metasploitable: https://sourceforge.net/projects/metasploitable/.

Это типовая ОС для экспериментов в области информационной безопасности, с которой следует начать при анализе уязвимостей.

Просканируйте эту виртуальную машину, используя nmap.

Попробуйте найти уязвимости, которым подвержена эта виртуальная машина.

Сами уязвимости можно поискать на сайте https://www.exploit-db.com/.

Для этого нужно в поиске ввести название сетевой службы, обнаруженной на атакуемой машине, и выбрать подходящие по версии уязвимости.

Ответьте на следующие вопросы:

Какие сетевые службы в ней разрешены?
Какие уязвимости были вами обнаружены? (список со ссылками: достаточно трёх уязвимостей)

1. С помощью nmap сканируем виртуальную машину с помощью команды  nmap -sV <IP-адрес-Metasploitable>, результат сканирования видим на скриншоте 1
2.  найденные службы и версии на сайте exploit-db.com. Вот три уязвимости, которые удалось выявить:

VSFTPD 2.3.4 (порт 21). В этой версии есть бэкдор: если в имени пользователя при FTP-подключении использовать последовательность, служба открывает прослушивающий shell на порту 6200 с правами root. На exploit-db.com можно найти соответствующий эксплойт (например, по запросу vsftpd 2.3.4 backdoor). 
Samba (порты 139/445). В версиях Samba 3.0.20–3.0.25rc3 при использовании нестандартной опции «Username Map Script» возникает уязвимость выполнения произвольных команд. Атакующий может указать в имени пользователя shell-метасимволы, чтобы выполнить произвольные команды до аутентификации. Эксплойт для этой уязвимости тоже есть в базе.
VNC (порт 5900). По умолчанию VNC-сервер в Metasploitable запускается с тривиальным паролем password. Это не классическая программная уязвимость (нет CVE), а проблема конфигурации, но она даёт прямой путь к системе: любой злоумышленник может подключиться VNC-клиентом и получить доступ к экрану машины.
